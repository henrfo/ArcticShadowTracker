# Source Code Archive

This directory contains all Python source code that was part of the ArcticShadowTracker project before archiving on 2025-09-18.

## Contents

- **analysis/**: Pattern analysis and risk scoring modules
- **detection/**: Vessel detection and monitoring algorithms  
- **infrastructure/**: Deployment and infrastructure configuration
- **models/**: Machine learning models (autoencoders, classifiers)
- **scripts/**: Executable scripts for data collection and processing
- **src/**: Core API management modules
- **utils/**: Utility modules for data collection, visualization, and processing
- **__init__.py**: Root package initialization file

## Purpose

These files represent the experimental and over-engineered systems that accumulated during development. They have been preserved for reference but moved out of the active workspace to create a clean environment for rebuilding the project with a focus on basic data collection.

## Usage

If you need to reference any of this code during the rebuild process, you can find the specific modules here. However, the goal is to start fresh with a simpler, more focused approach.
