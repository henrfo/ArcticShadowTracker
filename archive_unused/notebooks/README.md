# Notebooks Archive

This directory contains all Jupyter notebooks from the ArcticShadowTracker project before archiving on 2025-09-18.

## Contents

- **analysis/**: Data analysis notebooks including:
  - Autoencoder training
  - Pattern analysis
  
- **exploration/**: Initial exploration notebooks including:
  - Arctic vessel analysis demos
  - Initial data exploration

- **operational/**: Operational notebooks including:
  - Arctic surveillance dashboard
  - Interactive maps and visualizations
  - Legacy operational notebooks

- **outputs/**: Notebook output files and reports

- **barentswatch_test_v1.ipynb**: Standalone Barentswatch API testing notebook

## Purpose

These notebooks represent the exploratory data analysis, prototyping, and operational dashboard work that was done during the project development. They contain valuable insights into data patterns, visualization approaches, and analytical methods.

## Usage

These notebooks can be used for:
- Understanding data exploration approaches
- Reference for visualization techniques
- Examples of data analysis workflows
- Inspiration for simpler analytical approaches in the rebuild

## Note

Many of these notebooks may have dependencies on the archived source code and data. They are preserved for reference and methodological insights rather than immediate execution.
