# Tests Archive

This directory contains all test files from the ArcticShadowTracker project before archiving on 2025-09-18.

## Contents

- **integration/**: Integration test suites
- **test_*.py**: Unit tests for various modules including:
  - Autoencoder models
  - Cable monitoring
  - Dark vessel detection
  - Data persistence
  - Performance benchmarks
  - Risk scoring
  - Satellite data collection
  - Vessel detection
- **conftest.py**: Pytest configuration and fixtures

## Purpose

These test files represent the comprehensive testing framework that was built for the project. While they provide valuable insights into the expected behavior of the archived code, they are preserved here for reference as we rebuild the system with a simpler approach.

## Usage

These tests can serve as documentation for how the original system was expected to work and can be referenced when implementing new, simplified versions of similar functionality.
